# 🎓 Anya History Tutor

Telegram-бот с ИИ-ассистентом для подготовки к экзамену по истории Беларуси (9 класс).

---

## 🚀 Описание

**Anya History Tutor** — это интеллектуальный Telegram-бот, который помогает готовиться к экзамену по билетам по истории Беларуси.

Бот умеет:
- давать **полный ответ по билету**,
- делать **краткий конспект**,
- **объяснять тему простым языком**,
- задавать **дополнительные вопросы**,
- проводить **мини-проверку знаний** по билету.

👉 По сути — это персональный цифровой репетитор по истории Беларуси прямо в Telegram.

## 🎯 Возможности

- 📚 Полный ответ по экзаменационному билету
- ✏️ Краткий конспект по билету
- 💡 Простое объяснение сложной темы понятным языком
- ❓ Дополнительные вопросы по теме билета
- 🧠 Режим самопроверки: бот задаёт вопросы по одному
- 🤖 Ответы на основе собственных учебных материалов
- 🗂 Прямое чтение текстовых билетов из файлов `bilet_NN.txt`
- 📲 Удобное управление через кнопки в Telegram
- 🔁 Работа 24/7 на VPS через `systemd`
- 🔐 Контроль доступа: пробный режим, коды доступа, заявки и админ-команды

## ⚙️ Как это работает

1. Пользователь пишет в Telegram-бот
2. Бот определяет номер билета и выбранный режим
3. Если это запрос по билету, бот читает соответствующий файл `bilet_NN.txt`
4. Основной ответ строится на основе текста билета
5. При необходимости бот дополнительно использует `OpenAI API` и поиск по загруженным материалам
6. Ответ возвращается пользователю в Telegram

## 🧠 Логика источников

В проекте используется следующая логика приоритета:

1. **Главный источник** — текстовые билеты в папке `materials/bilety`
2. **Дополнительные материалы** — `official` и `primery_otvetov`
3. Бот не должен подменять тему билета другой темой из вспомогательных материалов

То есть сначала выбирается **точный билет**, а уже потом модель помогает:
- красиво объяснить,
- сократить,
- упростить,
- задать вопросы,
- проверить ученика.

## 🤖 Используемый ИИ

Проект интегрирован с:

- **OpenAI API**, модель `gpt-4.1-mini`
- **OpenAI File Search** по `vector_store_id` с загруженными учебными материалами

Используется для:
- генерации учебных ответов,
- упрощения объяснений,
- составления дополнительных вопросов,
- проверки ответов ученика,
- итоговой обратной связи в режиме самопроверки.

## 🔐 Контроль доступа

В боте реализована система контроля доступа:

- **Админы** — список Telegram `user_id` в `.env` (`ADMIN_USER_IDS`). Полный доступ + админ-команды.
- **Одобренные ученики** — добавляются вручную (`/grant`) или автоматически после ввода кода доступа.
- **Пробный режим** — все остальные пользователи получают **7 бесплатных вопросов** (значение настраивается через `TRIAL_LIMIT`).
- **Код доступа** — единая строка в `.env` (`ACCESS_CODE`). После ввода правильного кода ученик переходит в статус `approved`.
- **Заявка на доступ** — когда у пользователя кончились бесплатные вопросы, он может нажать кнопку «Запросить доступ». Заявка приходит админу прямо в Telegram, с кнопками «Одобрить / Отклонить».

Все данные о пользователях хранятся в локальной SQLite-базе `bot_users.db`.
**Эта база добавлена в `.gitignore`** и не попадает в репозиторий — она содержит личные данные пользователей.

### Что считается «вопросом»

Счётчик `trial_used` увеличивается на 1 при:
- запросе билета (полный / краткий / простой / доп. вопросы),
- запуске режима самопроверки (вся сессия = 1 запрос, ответы внутри не считаются),
- свободном вопросе боту.

Команды `/start`, `/help`, `/reset`, `/whoami`, нажатие кнопок без указания билета — **бесплатны**.

## 📚 Материалы

Проект работает на основе учебных материалов, подготовленных заранее:

- текстовые билеты;
- официальный список экзаменационных билетов;
- дополнительные примеры ответов.

Главная папка с билетами:

```text

```

Каждый билет хранится отдельно:

```text

bilet_03.txt
...
```

В начале каждого билета используется стандартная шапка, чтобы ИИ точно понимал тему и приоритет источника.

Пример:

```text

ЭТО ГЛАВНЫЙ ИСТОЧНИК ПО БИЛЕТУ 1.
При расхождениях с примерами ответов приоритет у этого файла.

Далее текст билета:
...
```

## 🔐 Переменные окружения

Создайте файл `.env` в корне проекта:

```env
# Telegram и OpenAI
TG_BOT_TOKEN=your_telegram_token
OPENAI_API_KEY=your_openai_key
VECTOR_STORE_ID=your_vector_store_id

# Контроль доступа
ADMIN_USER_IDS=123456789,987654321
ACCESS_CODE=anya2026
TRIAL_LIMIT=7
```

| Переменная        | Обязательно | Описание                                                                  |
|-------------------|-------------|---------------------------------------------------------------------------|
| `TG_BOT_TOKEN`    | да          | Токен Telegram-бота от BotFather                                          |
| `OPENAI_API_KEY`  | да          | Ключ OpenAI API                                                           |
| `VECTOR_STORE_ID` | да          | ID vector store с загруженными учебными материалами                       |
| `ADMIN_USER_IDS`  | нет         | Telegram user_id админов через запятую. Полный доступ + админ-команды     |
| `ACCESS_CODE`     | нет         | Код доступа для одобрения новых пользователей                             |
| `TRIAL_LIMIT`     | нет         | Сколько бесплатных вопросов даётся новым пользователям (по умолчанию 7)   |

> ⚠️ Если `ADMIN_USER_IDS` пустой — у бота не будет ни одного админа, и админ-команды работать не будут. Для получения собственного `user_id` используйте команду `/whoami` в боте.

## ☁️ Деплой на VPS (Beget)

Бот развёрнут на VPS и работает как системный сервис через `systemd`.

### Пример размещения на сервере

```text
/root/anya-history-tutor
```

### Пример systemd service

```ini
[Unit]
Description=Anya History Tutor Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/anya-history-tutor
Environment="PATH=/root/anya-history-tutor/venv/bin"
ExecStart=/root/anya-history-tutor/venv/bin/python /root/anya-history-tutor/main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

## 🚦 Первый запуск с контролем доступа

Когда вы только устанавливаете бота с включённым контролем доступа, надо «представиться» ему как админ:

1. Запустите бота на сервере (с пустым или неправильным `ADMIN_USER_IDS`).
2. Напишите боту команду `/whoami` — он ответит вашим `user_id`.
3. Откройте `.env` на сервере и впишите этот id в `ADMIN_USER_IDS=...`.
4. Перезапустите сервис: `systemctl restart anya-history-tutor`.
5. Снова напишите `/whoami` — теперь у вас должен быть полный доступ.
6. Можно проверить админ-командами: `/users`, `/stats`.

Дальше вы можете либо вручную одобрять учеников через `/grant <id>`, либо
выдать им код доступа из `ACCESS_CODE` — они сами введут его в боте.

## 📲 Примеры использования

### Для ученика

Пользователь может написать:

```text
Билет 1
```

```text
Билет 1 кратко
```

```text
Объясни просто билет 1
```

```text
Дополнительные вопросы к билету 1
```

```text
Проверь меня по билету 1
```

Или просто выбрать билет числом:

```text
1
```

А дальше пользоваться кнопками:

- Полный ответ
- Кратко
- Объясни просто
- Дополнительные вопросы
- Проверить меня
- Сменить билет

### Команды

Доступны всем:

- `/start` — приветствие
- `/help` — справка
- `/reset` — сбросить текущее состояние диалога
- `/whoami` — узнать свой Telegram `user_id`

Только для админов (`ADMIN_USER_IDS`):

- `/grant <user_id>` — выдать пользователю полный доступ
- `/revoke <user_id>` — отозвать доступ (вернуть в пробный режим)
- `/block <user_id>` — заблокировать пользователя
- `/users` — список всех пользователей бота
- `/stats` — статистика использования
